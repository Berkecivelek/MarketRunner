## Sorun Giderme

### 404 Hatası Alıyorsanız:
1. URL'nin tam olduğundan emin olun (MarketRunner ve privacy-policy.html dahil)
2. Birkaç dakika bekleyin (GitHub Pages deploy süresi)
3. Tarayıcı cache'ini temizleyin
4. GitHub repository'de dosyanın var olduğunu kontrol edin

### Sayfa Boş Görünüyorsa:
1. Tarayıcı console'unu kontrol edin (F12 veya Cmd + Option + I)
2. Network sekmesinde hataları kontrol edin
3. Sayfayı yenileyin (Cmd + R)
