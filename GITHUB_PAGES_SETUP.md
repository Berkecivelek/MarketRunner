# GitHub Pages URL Alma - Adım Adım Rehber

## ✅ Dosya Yüklendi

`PRIVACY_POLICY.html` dosyası GitHub repository'nize yüklendi.

## GitHub Pages'i Aktifleştirme

### Adım 1: GitHub Repository'nize Gidin

1. Tarayıcıda şu adrese gidin: `https://github.com/Berkecivelek/MarketRunner`
2. Repository sayfasında **Settings** sekmesine tıklayın (sağ üstte)

### Adım 2: Pages Ayarlarını Açın

1. Sol menüden **Pages** seçeneğine tıklayın
2. **Source** bölümünde:
   - **Branch**: `main` seçin (dropdown'dan)
   - **Folder**: `/ (root)` seçin
3. **Save** butonuna tıklayın

### Adım 3: URL'i Alın

1. Birkaç dakika bekleyin (GitHub Pages'in aktif olması için)
2. Sayfayı yenileyin (F5 veya Cmd + R)
3. **"Your site is live at"** yazısının altında URL'i göreceksiniz

**URL Formatı:**
```
https://berkecivelek.github.io/MarketRunner/PRIVACY_POLICY.html
```

### Adım 4: URL'i Test Edin

1. URL'i tarayıcıda açın
2. Privacy Policy sayfasının göründüğünü kontrol edin
3. Sayfa düzgün görünüyorsa hazırsınız!

## App Store Connect'e URL Ekleme

### Adım 1: App Store Connect'e Gidin

1. [appstoreconnect.apple.com](https://appstoreconnect.apple.com) adresine gidin
2. **My Apps** > **Market Runner** seçin
3. **App Information** sayfasına gidin

### Adım 2: Privacy Policy URL'i Ekleyin

1. **Privacy Policy URL** alanını bulun
2. URL'i yapıştırın: `https://berkecivelek.github.io/MarketRunner/PRIVACY_POLICY.html`
3. **Save** butonuna tıklayın

## Sorun Giderme

### URL Çalışmıyor

1. **Birkaç dakika bekleyin** - GitHub Pages'in aktif olması 1-5 dakika sürebilir
2. **Sayfayı yenileyin** - F5 veya Cmd + R
3. **Repository'nin public olduğundan emin olun** - Settings > Change visibility > Make public

### 404 Hatası Alıyorum

1. Dosya adının doğru olduğundan emin olun: `PRIVACY_POLICY.html`
2. Dosyanın repository'nin ana dizininde (root) olduğundan emin olun
3. GitHub Pages ayarlarında `/ (root)` seçili olduğundan emin olun

### HTTPS Hatası

- GitHub Pages otomatik olarak HTTPS sağlar
- URL mutlaka `https://` ile başlamalı

## Önemli Notlar

1. **Repository Public Olmalı**: GitHub Pages için repository public olmalı
2. **Dosya Adı**: `PRIVACY_POLICY.html` (büyük/küçük harf duyarlı)
3. **URL Formatı**: `https://[kullanıcıadı].github.io/[repository-adı]/[dosya-adı].html`
