# GitHub Pages 404 Hatası Çözümü

## Sorun
GitHub Pages'te `PRIVACY_POLICY.html` dosyası 404 hatası veriyor.

## Çözüm
Dosya adını küçük harflerle ve tire ile değiştirdik: `privacy-policy.html`

## Yeni URL'ler

### Çalışan URL'ler:
1. **Ana sayfa**: `https://berkecivelek.github.io/MarketRunner/`
2. **Privacy Policy (küçük harflerle)**: `https://berkecivelek.github.io/MarketRunner/privacy-policy.html`
3. **Privacy Policy (büyük harflerle - eski)**: `https://berkecivelek.github.io/MarketRunner/PRIVACY_POLICY.html` (çalışmayabilir)

## App Store Connect için Kullanılacak URL

**Önerilen URL:**
```
https://berkecivelek.github.io/MarketRunner/privacy-policy.html
```

## Test Adımları

1. Birkaç dakika bekleyin (GitHub Pages'in deploy etmesi için)
2. Şu URL'i tarayıcıda açın: `https://berkecivelek.github.io/MarketRunner/privacy-policy.html`
3. Sayfa açılıyorsa hazırsınız!

## Notlar

- GitHub Pages bazen büyük harfli dosya adlarında sorun yaşayabilir
- Küçük harfli dosya adları daha güvenilir
- Dosya adındaki boşluklar ve özel karakterler sorun yaratabilir
