# App Information Yapılandırması - Market Runner

## ✅ Tamamlanan

- [x] Age Ratings: 4+ (173 ülke için)
- [x] Made for Kids seçildi

## 📋 App Information Sayfasında Yapılacaklar

### 1. Subtitle (Alt Başlık)

**Adımlar:**
1. App Information sayfasında "Subtitle" bölümünü bulun
2. **Subtitle**: `Çocuklar için eğitici market oyunu` yazın
   - 30 karakter limiti var
   - Bu alt başlık App Store'da görünecek

### 2. Category (Kategori)

**Adımlar:**
1. "Category" bölümünü bulun
2. **Primary Category**: `Games` > `Puzzle` seçin
3. **Secondary Category**: `Education` > `Kids` seçin
4. "Save" tıklayın

### 3. Privacy Policy URL (ZORUNLU)

**ÖNEMLİ:** Privacy Policy URL'i eklemeden App Store'a gönderemezsiniz!

**Adımlar:**
1. "Privacy Policy URL" alanını bulun
2. Privacy Policy'i web'de yayınladıktan sonra URL'i buraya ekleyin
3. Örnek URL formatları:
   - GitHub Pages: `https://[kullanıcıadı].github.io/MarketRunner/privacy-policy.html`
   - Netlify/Vercel: `https://[proje-adı].netlify.app/privacy-policy`
   - Kendi web siteniz: `https://[siteniz].com/privacy-policy`

**Privacy Policy'i Henüz Yayınlamadıysanız:**
- `PRIVACY_POLICY.md` dosyasını HTML'e çevirin
- GitHub Pages, Netlify veya Vercel'de yayınlayın
- URL'i App Store Connect'e ekleyin

### 4. Age Suitability URL (Opsiyonel)

- Şu anda boş - bu opsiyonel, doldurmanıza gerek yok

### 5. App Encryption Documentation

**Adımlar:**
1. "App Encryption Documentation" bölümünü kontrol edin
2. `app.json`'da `ITSAppUsesNonExemptEncryption: false` ayarlı
3. Bu durumda ekstra dokümantasyon yüklemenize gerek yok
4. Eğer soru sorulursa: "No, my app does not use encryption" seçin

## Sonraki Adımlar

App Information tamamlandıktan sonra:
1. ✅ Subtitle ekleyin
2. ✅ Category seçin
3. ✅ Privacy Policy URL ekleyin (ZORUNLU)
4. ⏳ Ekran görüntüleri hazırlayın
5. ⏳ Build yükleyin (EAS Build ile)

## Önemli Notlar

- Privacy Policy URL **ZORUNLU** - App Store review için gerekli
- Subtitle App Store'da görünecek - dikkatli seçin
- Category seçimi uygulamanın keşfedilebilirliğini etkiler
